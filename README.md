# Inforbot
Chatbot com IA utilizando GPT-5 Nano, por meio do framework Flask e Langchain, com suporte a múltiplas conversas.

# Como rodar
```
# Win => python -m venv venv
# Lin => python3 -m venv venv
```
```
# Win => venv/scripts/Activate
# Lin => source venv/bin/activate
```
```
pip install -r requirements.txt
```
```
flask --app inforbot:app run   
```
